# M.Sc. IT Semester 1 — Linux Practical Programs

Organized from the uploaded **M.Sc. IT Sem-1 Practical Journal**.

## Repository contents

| Folder | Practical title | Main file |
|---|---|---|
| `01-basic-user-status-commands` | Basic & User Status Unix/Linux Commands | `basic_user_status.sh` |
| `02-arithmetic-operations` | Arithmetic Operations with Unix/Linux | `arithmetic.sh` |
| `03-count-lines-words-characters` | Count lines, words and characters in a file | `count_file_stats.sh` |
| `04-common-names-in-two-files` | Display names found in both files | `common_names.sh` |
| `05-inode-number` | Find the inode number of a file | `inode_number.sh` |

| `07-user-count-pipeline` | Display and save logged-in user information | `user_count_pipeline.sh` |
| `10-reverse-command-line-arguments` | Print command-line arguments in reverse order | `reverse_arguments.sh` |
| `11-smallest-of-three` | Find the smallest of three numbers | `smallest_three.sh` |

## Run a script in Kali Linux

From the repository directory:

```bash
cd 01-basic-user-status-commands
sh basic_user_status.sh
```

Or run a script directly from its folder using `sh filename.sh`.

## Notes
- The practical numbers follow the numbers shown in the journal index; they are not sequential because the journal lists selected practicals.
- Use these scripts for practice. Read each script before running it.
- The ownership/group demonstration in Practical 6 uses `sudo` and changes system users/groups; read its instructions carefully and only run it in a lab VM where you have permission.
